# v0.0.21 - Tela inicial/login com fundo preto

## Regra aprovada

A tela inicial/login do Automind.Treinamentos deve usar fundo preto/escuro sólido (`#121019`).

O gradiente institucional Automind (`#FA094E` -> roxo/navy) deve ser reservado para elementos de destaque, como botões, bordas, marca e pequenos acentos. Ele não deve substituir o fundo principal da tela inicial.

Esta regra é específica e permanente para o Automind.Treinamentos e prevalece sobre qualquer padrão genérico de design que sugira um fundo em gradiente.
