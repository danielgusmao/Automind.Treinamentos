# v0.0.4 - Administração, lembretes Teams e modelo de treinamento

## 1. Edição de questões

A página `Admin/Questions` agora possui `Editar` e `Excluir` para cada questão. A edição permite alterar:

- enunciado;
- alternativas A, B, C e D opcional;
- resposta correta.

O backend valida que o gabarito corresponde a uma alternativa existente. Alterações em questões de um treinamento publicado atualizam o snapshot do treinamento.

## 2. Pendências e Teams

A página `Admin/Pending/{id}` continua comparando os usuários elegíveis do AD com as conclusões do treinamento.

Para usuários pendentes:

- checkbox de seleção;
- botão `Enviar Teams` individual;
- seleção coletiva por `Marcar todos os pendentes`;
- botão `Enviar Teams aos selecionados`.

Para usuários concluídos:

- status `Concluído`;
- sem checkbox;
- sem botão de envio.

Antes do envio o servidor consulta novamente o AD e as conclusões. O destinatário é o e-mail corporativo do usuário elegível.

### Mensagem

O lembrete contém:

- saudação;
- nome do treinamento;
- tempo estimado;
- link direto para `Training/Take/{id}`;
- identificação de que a mensagem veio do portal `Automind.Treinamentos`.

### Webhook

Contrato:

```json
{
  "recipient": "usuario@automind.com.br",
  "text": "mensagem HTML"
}
```

O segredo é externo ao repositório:

```text
Automind__Teams__WebhookUrl
```

O código também lê:

```text
Automind__Teams__Enabled
```

Somente URL HTTPS é aceita para o webhook. Sem uma URL válida o envio permanece desabilitado na interface. O segredo nunca deve ser versionado.

## 3. Novo treinamento

A tela `Admin/CreateTraining` inclui um guia visual e o campo `Conteúdo` é iniciado com um modelo editável contendo:

1. módulo e objetivo;
2. conteúdo;
3. boas práticas;
4. exemplo prático;
5. orientação para dúvida/incidente;
6. resumo final.

A tela também explica o formato das questões e mostra um exemplo com alternativas e gabarito. Depois de salvar os metadados, o fluxo segue para o banco de questões.

## 4. Identidade visual e versão

- `_informatica` não é mais exibido no cabeçalho; aparece `Administrador`.
- a regra de autorização AD não foi alterada;
- aviso de HTTP removido da tela de login;
- rodapé mostra somente a versão;
- topbar e rodapé usam `AppVersionInfo`, baseado na versão do assembly;
- versão do pacote: `v0.0.4`.

## 5. Auditoria

Cada tentativa de lembrete Teams registra no JSONL:

- operador;
- treinamento;
- destinatário;
- login;
- link enviado;
- sucesso/falha;
- erro técnico quando existir.

O webhook não é registrado.
